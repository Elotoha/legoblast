# legoblast
Legoblast game I (Gogo) have developped in 1996 in Assembler 68020/68030 on Amiga. Experiment to convert it to Python or another language.

Complete game:
https://aminet.net/package/game/2play/LegoBlast

- Dynablaster/Bomberman clone multiplayer
- Totaly Freeware !
- 100% assembly language (tested on 68000,020,030)
- Works well on A600 not extended !
- 6 worlds of 20 levels with many features as pipes, bouncers, extra bonus...
- Handles Bomb pushing, Energy transmission, Flares divisions
- The Flares are handled by the best way in my mind: flare growing handling!
- Team battle + special levels allowed for team battle
- If not enough chip ram, runs with less sounds! (displayed)

- You can customise game sounds (please send me cool ones ! :-) )
  by editing text file "samples.def"
- You can add your own music modules (P6 format, in 3 voices max)
- You can edit your own levels with AMOS program included
  (This part must be improved, lack of docs, not very simple)
